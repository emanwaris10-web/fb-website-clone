# Facebook Website Clone (`fb-website-clone`)

A responsive front-end clone of the Facebook web application built to practice modern UI design, layout structuring, and interactive web development concepts.

## 🚀 Features

- **User Authentication UI:** Clean login and sign-up page layout modeled after Facebook's interface.
- **Responsive Design:** Adapts smoothly across desktop, tablet, and mobile screens.
- **Navigation Bar:** Top header featuring search bar, navigation icons, and user profile menu.
- **News Feed Layout:** Post cards with like, comment, and share UI elements.
- **Sidebars:** Left navigation shortcuts and right-side contacts/trending section.

## 🛠️ Technologies Used

- **HTML5** – Semantic page structure
- **CSS3** – Styling, Flexbox, and Grid layouts
- **JavaScript** – Basic DOM interactivity *(add or remove based on what you use)*
